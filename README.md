# PowerModes（电源模式）

一个原生 macOS 菜单栏工具，用预设快速切换屏幕休眠、系统睡眠和合盖行为。

## 功能

- 只常驻菜单栏，不占用 Dock
- 点击菜单栏图标即可切换电源预设
- 菜单栏图标随当前模式变化
- 每次启动只请求一次管理员授权，本次运行内切换无需重复授权
- 支持编辑和新增自定义预设
- 自动跟随 macOS Light / Dark 外观

内置三个预设：

- **正常模式**：允许系统睡眠和合盖睡眠；电池 15 分钟、接电 30 分钟后关屏
- **长任务模式**：系统保持运行，合盖仍然睡眠；电池 10 分钟、接电 20 分钟后关屏
- **合盖任务模式**：系统和合盖均不睡眠；电池 3 分钟、接电 10 分钟后关屏

> 合盖继续运行时，请勿将 Mac 放进电脑包，以免积热。

## 系统要求

- macOS 14 或更高版本
- Apple Silicon 或支持 Swift 6.2 的 macOS 开发环境

## 构建

```bash
swift test
swift build -c release
./scripts/package-app.sh
```

生成的 App 位于 `dist/电源模式.app`，可复制到 `/Applications`。

## 权限与安全

修改 macOS 电源设置需要管理员权限。App 启动时通过系统授权窗口创建一个仅限当前进程、仅能执行内置 Helper 的临时授权会话：

- 不读取、保存或传输管理员密码
- 不联网、不采集数据
- 不安装常驻后台服务
- App 退出后删除临时授权规则
- Helper 仅接受经过范围校验的固定电源参数

## 卸载

先切回“正常模式”并退出 App，再删除 `/Applications/电源模式.app`。
